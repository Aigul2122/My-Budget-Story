# My Budget Story

Личный трекер семейного бюджета. Работает полностью в браузере — все данные
(счета, операции, категории) хранятся только в localStorage вашего браузера
и никогда не отправляются никуда, включая GitHub.

## Как открыть

Просто откройте `dashboard.html` по ссылке GitHub Pages, например:
```
https://ваш-логин.github.io/my-budget-story/dashboard.html
```

## Важно про общий доступ

Если этой же ссылкой поделиться с другим человеком — он увидит **пустое**
приложение, а не ваши данные: у каждого свой браузер = своё отдельное
хранилище. Это удобно, если хотите:
- показать кому-то само приложение, не раскрывая свои цифры;
- дать детям каждому свою чистую копию.

Если нужно **передать именно свои данные** другому человеку (например,
финансовому консультанту) — используйте «Настройки → Экспорт в JSON»,
отправьте файл, а он загрузит его через «Настройки → Восстановить из JSON»
у себя. Это разовый снимок, не постоянная синхронизация.

## Файлы

- `dashboard.html` — Главная
- `operatsii.html` — Операции (доходы, расходы, переводы)
- `kapital.html` — Капитал (счета, депозиты, сейфы)
- `nastroiki.html` — Настройки (категории, резервное копирование, импорт)
- `zagruzka.html` — Загрузка (демонстрационный экран)
- `store.js`, `mvp.css`, `responsive.css` — общая логика и стили
